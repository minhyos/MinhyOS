## 📌 Tentang Minhy OS

**Minhy OS** (*Mini Hybrid Operating System*) adalah distribusi Linux kustom berbasis **Debian** yang dirancang khusus untuk memberikan performa maksimal pada PC/laptop spesifikasi rendah (*PC Kentang*).

Dengan konsep **Hybrid**, Minhy OS mampu menjalankan aplikasi bawaan Linux secara *native* sekaligus menjalankan aplikasi/game Windows (`.exe`) tanpa hambatan berkat integrasi **Wine** dan **Winetricks** yang sudah terkonfigurasi secara *out-of-the-box*.

---

## 🔥 Fitur Utama

- 🏎️ **Super Ultra-Lightweight:** Hanya mengonsumsi RAM sebesar **~500 MB** pada kondisi *idle*.
- 💾 **Storage Hemat:** Hanya membutuhkan ruang penyimpanan sebesar **~9 GB** setelah diinstal.
- ⚡ **Sistem Hybrid Seamless:** Jalankan aplikasi Linux Debian (`.deb`) dan file eksekusi Windows (`.exe`, `.msi`) secara berdampingan.
- 🛠️ **Pre-configured Compatibility Layer:** Sudah dibekali Wine, Winetricks, serta pendorong grafis untuk pengalaman bermain game dan produktivitas yang optimal.
- 🎨 **Tampilan Modern & Minimalis:** Antarmuka yang bersih, cepat, dan responsif tanpa *bloatware* yang memberatkan CPU.

## 🚀 Cara Penggunaan

1. **Unduh ISO Minhy OS** dari halaman [Releases](../../releases).
2. **Buat Bootable Flashdisk** menggunakan alat seperti *Ventoy* atau *Rufus*.
3. **Boot & Install** menggunakan installer bawaan (Calamares).
4. **Selesai!** Minhy OS siap digunakan untuk kebutuhan harian, koding, hingga gaming ringan.
